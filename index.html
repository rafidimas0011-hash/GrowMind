Tidak. GrowMind adalah alat untuk menyusun rencana, mencatat transaksi, dan mengevaluasi proses. Tidak ada sinyal beli atau jual.
Tidak oleh aplikasi ini. Data disimpan di localStorage browser pada perangkat yang kamu gunakan. Menghapus data browser dapat menghapus catatan; gunakan ekspor JSON untuk cadangan.
Simulasi menggunakan asumsi return tetap per periode, sehingga tidak mencerminkan volatilitas, kerugian beruntun, slippage, likuiditas, atau perubahan kondisi pasar. Angka adalah ilustrasi matematis.

Catatan risiko. GrowMind hanya alat bantu pencatatan dan simulasi, bukan nasihat keuangan, rekomendasi investasi, atau ajakan bertransaksi.
